# Investigación sobre Render (Jordan Iza)

Render es una plataforma que permite desplegar aplicaciones desde contenedores Docker conectados a un repositorio GitHub.

### Pasos de despliegue:
1. Crear cuenta en Render.
2. Conectar el repositorio de GitHub.
3. Detectar el Dockerfile automáticamente.
4. Configurar puerto (por defecto 3000).
5. Render crea un enlace público.

### Ventajas:
- Fácil integración con GitHub.
- Plan gratuito.
- Despliegue automático en cada push.

### Desventajas:
- En modo gratuito los contenedores se duermen.
